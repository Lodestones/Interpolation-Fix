# Interpolation Fix - v1.2.0
## Server Opt-In and Settings Screen
### PLUGIN UPDATES
**Server opt-in**: The fix now turns on by default only for servers that support it, and in singleplayer, so it can't get you flagged on servers whose anticheat expects 26.3.
**Three modes**: Pick Server Opt-In (default), Always, or Off. The keybind now cycles through them.
**Mod Menu screen**: Change the mode in game and see whether the server you're on supports the fix.
**AntiStutter servers**: Servers that support LokaMC's AntiStutter turn the fix on too.
**Paper plugin**: Server owners can opt in by dropping the Interpolation Fix plugin into their plugins folder (Paper, Purpur and Folia 1.21.6+).
### PLUGIN CHANGES
**Fabric API**: Now required.
**Existing settings**: If you left the fix on in v1.1.0, you're moved to Always. If you turned it off, it stays Off.
