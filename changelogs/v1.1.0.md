# Interpolation Fix - v1.1.0
## Toggle Keybind
### PLUGIN UPDATES
**Toggle keybind**: Added "Toggle Interpolation Fix" under Controls > Misc. Press it to switch between the 26.2 smoothing and vanilla 26.3 smoothing instantly, no rejoining needed. It's unbound by default so it never clashes with your other keys.
**Remembers your choice**: The on/off setting is saved and kept between restarts.
### PLUGIN CHANGES
**Anticheat warning**: Servers whose anticheat is built around 26.3 can flag the fix for Reach. Turn it off before joining one, or keep it for recordings.
